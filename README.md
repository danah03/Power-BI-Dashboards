# Data Job Insights Dashboard (Power BI)
![Main Dashboard](/images/project%201-%20page%201.png)
## Project Overview
Navigating the data job market can feel fragmented and overwhelming. This project turns thousands of real-world 2024 data science job postings into an interactive, central analytical hub designed for active job seekers, career transitioners, and professionals looking to evaluate market rate compensation.

By translating raw job titles, compensation packages, and global locations into clear visualizations, the dashboard delivers actionable insights into hiring demand and salary trends.


* **Source File:** [`Data_Jobs_Dashboard.pbix`](Data_Jobs_Dashboard.pbix)

---

##  Core Competencies & Power BI Skills

* **Data Engineering & ETL (Power Query):** Executed data preparation routines—cleaning missing values, standardizing column data types, and engineering custom conditional fields.
* **Analytical Calculations (Measures):** Implemented aggregations to extract key performance indicators, such as total position volume and median annual pay.
* **Data Visualization & UX:**
  * **Chart Selection:** Built column, bar, line, area, and card visuals to effectively highlight trends, rankings, and high-level KPIs.
  * **Geospatial Mapping:** Utilized map features to display international job distribution patterns.
  * **Detail Tables:** Incorporated sortable tabular layouts for granular data review.
* **User Interactivity & Navigation:**
  * **Slicers:** Applied single- and multi-select filtering for title-based queries.
  * **Bookmarks & Buttons:** Integrated custom navigation buttons to deliver a seamless app-like UI.
  * **Drill-Through Actions:** Configured page-to-page navigation to transition from macro metrics to detailed job analyses.

##  Dashboard Architecture

### Page 1: Executive Market Overview
![Main Dashboard](/images/project%201-%20page%201.png)
The primary landing view provides a macro-level summary of the industry landscape. Users can quickly evaluate global job volume, broad salary baselines, and top-ranking roles across the market.

### Page 2: Role-Specific Deep Dive (Drill-Through)
![Main Dashboard](/images/project%201-%20page%202.png)
A contextual target page that isolates individual roles. It exposes detailed breakdowns per job title, including remote vs. hybrid work distribution, key recruitment sources, salary ranges, and explicit geographic heat maps.

---

##  Key Takeaway
This project demonstrates how raw job market data can be modeled and visualized to directly inform career decisions, helping candidates make data-driven choices about salaries, target roles, and remote work preferences.
